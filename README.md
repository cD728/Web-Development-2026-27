# Web-Development-2026-27
Note: The images used in this website are from jojowiki.com

## Purpose

This website is a JoJo's Bizarre Advanture Fan Page.
In it I talk about my opinion on each part while also showing each parts' JoJo protagonist and in the parts I can its stand.

## How the website works

This website is a single page that changes its content based on the hash of the url. It was made like this to add some usability if needed to link a part of the website in another page.
To navigate the website the button on the navbar can be used, in combination with the images that appear at larger resolutions to navigate, and with the buttons that appear on the content in smaller screens.
The website also includes a way to change the website from dark mode to white mode.
